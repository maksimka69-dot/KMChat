# Changelog

Значимые изменения проекта. Формат — по датам, от новых к старым.

## [Текущая версия] — форматирование кода

- Код полностью переформатирован для читаемости: CSS разбит по одному свойству на строку, HTML получил корректную вложенную индентацию, JS-функции разбиты на читаемые многострочные блоки.
- Все `\uXXXX`-escape-последовательности в JS-строках заменены на обычные символы (кириллица, эмодзи) — код читается напрямую, без расшифровки escape-кодов.
- Функциональность не менялась.

## Миграция STT-провайдера: AssemblyAI → Deepgram

**Проблема:** конфигурация AssemblyAI (`universal-3-5-pro`) не поддерживала русский язык, из-за чего не работал перевод для русскоязычных участников.

**Решение:** заменили распознавание речи на **Deepgram Nova-3 Multilingual** (`model=nova-3&language=multi`).

### Что изменилось технически

- `AAI_API_KEY` → `DEEPGRAM_API_KEY`.
- Endpoint: `wss://streaming.assemblyai.com/v3/ws` → `wss://api.deepgram.com/v1/listen`.
- Параметры подключения: `speech_model`/`encoding: pcm_s16le`/`language_code` → `model: nova-3`/`encoding: linear16`/`language: multi`.
- **Авторизация в браузере.** Изначально предполагалось передавать ключ через query-параметр `?token=` (по аналогии с AssemblyAI). При проверке актуальной документации Deepgram выяснилось, что официально задокументированный способ для браузера — это `Sec-WebSocket-Protocol` (второй аргумент конструктора `WebSocket`):

  ```js
  new WebSocket(url, ['token', DEEPGRAM_API_KEY]);
  ```

  Это и было реализовано вместо query-параметра.
- Формат сообщений транскрипции другой: вместо `type: 'Turn'` / `end_of_turn` (AssemblyAI) обрабатываются сообщения `type: 'Results'` с полями `is_final` и `speech_final` (Deepgram) — по ним определяется, когда реплика закончена и её нужно переводить и отправлять собеседнику.
- Функции переименованы для ясности: `startAssemblyAI`/`stopAssemblyAI` → `startDeepgram`/`stopDeepgram`, переменные `aaiWs`/`aaiAudioCtx`/… → `dgWs`/`dgAudioCtx`/…

### Что не менялось

- Перевод текста (MyMemory API) — проблема была только в распознавании речи, перевод русского и раньше работал корректно.
- Логика видеозвонка (PeerJS/WebRTC) — не затрагивалась.
